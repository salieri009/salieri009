## About Me

- **시드니 공과대학교(UTS)** 정보기술 학사를 졸업했습니다. 전공은 Enterprise Software Development, 부전공은 Computer Graphics and Animation입니다.
- **Cloud, DevOps, Platform Engineering** 방향으로 나아가고 있습니다. AI 모델 자체를 만드는 것보다, 서비스가 규모 있게 안정적으로 돌아가도록 만드는 인프라 — 프로비저닝, 배포, 관측성, 운영 — 에 관심이 있습니다.
- 현재 **Docker, Kubernetes, Terraform, AWS/Azure, Linux** 를 직접 다루며 GitHub Actions와 Azure DevOps로 CI/CD 파이프라인을 구성하고, 동시에 System Design·운영체제·컴퓨터 구조 등 기본기를 다지고 있습니다.
- **Java와 Python** 기반의 백엔드 역량을 갖추고 있으며, TypeScript·React·Vue로 풀스택 프로젝트를 진행한 경험이 있습니다.
- **velog** 에 학습 중심의 엔지니어링 글을 씁니다 — Cloud, Docker, Kubernetes, Backend 시리즈. 단순 기록이 아니라 다른 개발자가 읽고 배워갈 수 있는 글을 지향합니다.
- 코드 밖에서는 구어, 수화, 예술 등 모든 형태의 언어에 꾸준히 관심을 두고 있습니다.
