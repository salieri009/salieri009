## About Me

- **シドニー工科大学（UTS）** で情報技術学士を修了しました。専攻は Enterprise Software Development、副専攻は Computer Graphics and Animation です。
- **Cloud・DevOps・Platform Engineering** の方向へ進んでいます。AI モデルそのものをつくることよりも、サービスが大規模に安定して動くための基盤 — プロビジョニング、デプロイ、オブザーバビリティ、運用 — に関心があります。
- 現在は **Docker、Kubernetes、Terraform、AWS/Azure、Linux** を実際に触りながら、GitHub Actions と Azure DevOps で CI/CD パイプラインを構築し、同時に System Design・オペレーティングシステム・コンピュータアーキテクチャなどの基礎を固めています。
- **Java と Python** によるバックエンドの基盤を持ち、TypeScript・React・Vue でのフルスタック開発経験があります。
- **velog** で学びを中心とした技術記事を書いています — Cloud、Docker、Kubernetes、Backend シリーズ。単なる記録ではなく、他の開発者が読んで学べる記事を目指しています。
- コードの外では、話し言葉・手話・芸術など、あらゆる形の言語に興味を持ち続けています。
